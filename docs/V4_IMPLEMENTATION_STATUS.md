## Runtime boundaries — not fabricated passes

- No configured callable Astra adapter with verified Ultra capability was available. The absolute server-side `PREMIERE316_ASTRA_ADAPTER` discovery/generation contract is implemented; missing capability fails without fallback.
- Local role/artifact validation includes the user's exact regular GAIN Q8_0 file beneath the MTP-labeled LM Studio folder. Labels alone never verify weights. No fresh large-model inference was performed for acceptance.
- ACE-Step 1.5 XL SFT and Stable Audio 3 Small-SFX are wired through offline workers, configuration and owned jobs; installed packages/weights and live inference remain unverified. No auto-download or simulated output replaces them.
- Acting, physical plausibility, framing, motif identity and actual user-film chronology require real output and human viewing/listening. The review operations exist; tests cannot grant those approvals.
- Supported native workflows/modes remain the execution boundary; unsupported repaint/continuation capabilities are not invented.
- Historical values remain in owning versions, corrections, job packets and delivery manifests. The registry is a view, not a second historical database; it cannot recover history never stored by legacy projects.
- Native Electron window interaction and physical keyboard zoom were not automated. Renderer checks and package audits do not equal a live native-media production run.
- The OG skill's fallback retains the platform share-card placeholder when its specified image-generation pipeline is unavailable. Platform branding remains intact.
